# Gem Grid

A 9x9 block puzzle game built with Flutter + Flame. See `CLAUDE.md` for the game design
and code layout.

- **Play in browser:** https://akash-9794.github.io/Game/
- **Android APK:** Actions tab → latest "Build" run → Artifacts → `gem-grid-debug-apk`

## Modes
- **Classic** – endless, beat your best score.
- **Adventure** – 30 levels with goals (reach a score, clear diamond gems) and a move limit.
  Earn up to 3 stars per level.
