# Gem Grid — notes for Claude

Gem Grid is a mobile block-puzzle game built with **Flutter** and the **Flame** game engine.
The Flutter project lives at the repository root (package name `gem_grid`). Portrait only.

## The game
- **Board:** 9x9 grid of cells.
- **Turns:** the player is offered **3 shapes per turn**. They drag each shape onto the board
  in any order. When all 3 are placed, 3 new shapes are dealt.
- **Clearing:** any **full row or full column** is cleared (both at once if both are full).
- **Scoring:** points for each cell placed, plus points per cleared line.
  Clearing several lines at once and clearing on **consecutive placements (combo)**
  multiply the reward. A placement that clears nothing resets the combo.
- **Game over:** when none of the remaining shapes fits anywhere on the board.
- **Modes:**
  - **Classic** — endless play, chase the high score.
  - **Adventure** — level-based play with goals (e.g. reach a score, clear target gems).
- **Monetization (later):** Google **AdMob** ads (banner, interstitial between games,
  rewarded ads e.g. for a continue). Not added yet — keep ad code isolated in its own
  service class so the game works without it (and on web, where AdMob is unavailable).

## Architecture rules
- **Game logic is pure Dart** in `lib/logic/`. Files there must NOT import
  `package:flutter`, `package:flame`, or `dart:ui`. This keeps rules fast to unit-test.
- **Rendering and input** live in `lib/game/` (Flame components). They read state from
  the logic classes and call into them; they never contain game rules.
- **Flutter UI** (menus, mode select, settings, overlays) lives in `lib/ui/` when added.
- Every logic class gets **unit tests** in `test/logic/`. Add or update tests with every
  rule change.

## Layout
```
lib/main.dart                       App entry: locks portrait, loads saved data, starts the app
lib/logic/                          PURE DART RULES (no Flutter/Flame imports)
  shape.dart                        Shape + list of all dealable shapes
  board.dart                        9x9 board, placement, line clears, combo scoring, target gems
  tray_game.dart                    Shared rules: tray of 3 pieces, dealing, "no moves left"
  classic_game.dart                 Classic mode (endless, game over when nothing fits)
  adventure_game.dart               Adventure mode: goals, move limit, win/lose, 1-3 stars
  levels.dart                       The 30 Adventure levels (fixed formula + seed)
  adventure_progress.dart           Unlocked levels + stars, save/load format
lib/game/                           FLAME RENDERING (board + tray only, no rules)
  gem_grid_game.dart                FlameGame: layout, drag handling, calls the logic
  board_component.dart              Draws board, target gems, drag preview, clear animation
  piece_component.dart              Draggable tray piece
  floating_text.dart                "+40" / "Combo x2" popups
  gem_painter.dart                  Colours, gem block and diamond drawing
lib/ui/                             FLUTTER SCREENS
  app.dart                          MaterialApp + dark theme
  home_screen.dart                  Title, Classic / Adventure buttons, How to play, Settings
  level_select_screen.dart          30-level grid with stars and locks
  game_screen.dart                  Score bar + Flame game + panels (intro, pause, game over,
                                    level complete, level failed); Android back = pause
  settings_screen.dart              Sound + vibration toggles, reset progress, version
  how_to_play_screen.dart           Rules explained
  widgets.dart                      Shared widgets (buttons, stars, gem icons, header)
lib/services/game_storage.dart      Saves best score, Adventure stars, settings (shared_preferences)
lib/services/sound_service.dart     Sound effects via flame_audio pools (silent in tests)
assets/audio/                       Sound effects (generated by tools/make_sounds.py)
assets/icon/                        App icon source (generated by tools/make_icon.py)
tools/                              Python scripts that generate sounds and the icon
test/logic/                         Unit tests for every logic class (incl. a bot that proves
                                    every level is winnable)
test/ui/                            Widget tests for the screens and a full win/lose flow
test/game/                          Flame game smoke test
.github/workflows/build.yml         CI: test, Android APK, web deploy to GitHub Pages
```

## Notes
- If you change level formulas in `levels.dart`, run `flutter test test/logic/levels_test.dart`:
  it prints the bot's win rate per level and fails if any level is impossible.

- Sounds: edit and run `python3 tools/make_sounds.py`. Icon: edit and run
  `python3 tools/make_icon.py`, then `dart run flutter_launcher_icons`.
- CI also runs on pull requests (tests + APK + web build, no deploy). Check it is green
  before merging.

## Commands
- `flutter test` — run all tests (must pass before pushing)
- `flutter analyze` — lint (keep at "No issues found")
- `flutter build apk --debug` — Android debug APK
- `flutter build web --release --base-href /<repo-name>/` — web build for GitHub Pages

## Environment
The owner has no local setup. Everything is built and verified in CI
(GitHub Actions, see `.github/workflows/build.yml`). Pushes to `main` run tests,
upload a debug APK artifact, and deploy the web build to GitHub Pages.
